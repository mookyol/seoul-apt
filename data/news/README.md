# 부동산 이슈 브리핑 (data/news/)

매일 아침 7시(KST) Claude 예약 작업(Routine)이 웹 검색으로 서울 부동산 뉴스·정책을 모아 요약해 커밋합니다.
웹앱의 📰 이슈 탭이 이 파일들을 보여줍니다 (build_site.py가 최근 14일치를 site/data/news/로 복사).

## 파일
- `YYYY-MM-DD.json` — 그날 브리핑 (KST 날짜)
- `latest.json` — 가장 최근 브리핑과 같은 내용

## 형식
```json
{
  "date": "2026-10-06",
  "generated_at": "2026-10-06T07:03:00+09:00",
  "briefing": ["오늘의 핵심 3줄 요약 1", "2", "3"],
  "policy": [
    {"title": "정책·발표 제목", "agency": "국토교통부", "date": "2026-10-05",
     "summary": "무엇이 바뀌고 누구에게 영향이 있는지 1~2문장", "url": "https://..."}
  ],
  "topics": [
    {"topic": "대출·금리", "items": [
      {"title": "기사 제목", "source": "언론사", "date": "2026-10-05",
       "summary": "직접 쓴 1~2문장 요약", "url": "https://..."}
    ]}
  ],
  "watch": ["이번 주 확인할 일정·발표 (예: 10/8 한국은행 기준금리 결정)"]
}
```
- topic 이름: 대출·금리 / 세금 / 청약·분양 / 공급·재건축 / 토지거래허가·규제 / 시장 동향
- 요약은 직접 작성 (기사 문장을 그대로 옮기지 않음), 원문 링크 필수
